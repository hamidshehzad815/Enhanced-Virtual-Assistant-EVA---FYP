EVA SYSTEM SETUP (WINDOWS)
==========================

Required Software
-----------------
1. Node.js 18+ (includes npm)
2. Python 3.11+ (added to PATH)
3. Docker Desktop (for Duckling)
4. MongoDB Community Server
5. Git (recommended)

Project Structure
-----------------
- Eva_Backend_Server
- Eva_AI_Server
- setup_windows.ps1

Environment Files
-----------------
Make sure these files exist and are configured:
1. Eva_Backend_Server\.env
2. Eva_AI_Server\.env

Quick Setup
-----------
From project root:
1. Open PowerShell
2. Run:
   .\setup_windows.ps1

Optional (auto-start services except MongoDB):
   .\setup_windows.ps1 -Start

Manual Run Commands
-------------------
1. Start MongoDB:
   mongod --dbpath <YOUR_DB_PATH>

2. Start Duckling:
   docker run --rm -p 8000:8000 rasa/duckling

3. Start Backend:
   cd Eva_Backend_Server
   npm run dev

4. Start AI Server:
   cd Eva_AI_Server
   .\.venv\Scripts\python -m uvicorn main:app --host 0.0.0.0 --port 8080 --reload

Default Ports
-------------
- Backend: 3000
- AI Server: 8080
- Duckling: 8000
- MongoDB: 27017

Basic Health Check
------------------
After startup:
1. Backend health:
   http://localhost:3000/health
2. AI health:
   http://localhost:8080/health
