BEHAVIORAL SEED DATA — TEST CASES

Seed script:
  cd Eva_AI_Server
  PYTHONPATH=. python scripts/seed_behavioral_activity_logs.py --user-id YOUR_USER_ID
  PYTHONPATH=. python scripts/seed_behavioral_activity_logs.py --user-id YOUR_USER_ID --profile sparse
  PYTHONPATH=. python scripts/seed_behavioral_activity_logs.py --user-id YOUR_USER_ID --conflict-task

Replace YOUR_USER_ID with your logged-in Mongo user _id.
Re-run with same user to replace seed data (clears source=behavioral_seed first).

Expected seed shape (profile=full):
  Mon  — 12 completions (strong 6–8 PM; weak 10 AM)
  Tue  —  9 completions (strong 7–8 PM)
  Wed  —  3 completions (below per-day threshold 5)
  Thu  —  6 completions (strong 10–11 AM)
  Fri  —  2 completions (unreliable)
  Sat/Sun — 0
  Total — 32 task_completed (passes global threshold 20)
