CLF_Improvement Guide (CLF1 + CLF2)
==================================

Goal
----
Improve EVA's two classifiers so they handle:
- ambiguous "show" messages
- behavioral vs scheduling confusion
- learning_create vs wrong intent ("I need to learn python")
- multi-command vs single command
- confirmations ("yes", "no") vs commands

CLF2 labels (8 intents — production router)
-------------------------------------------
scheduling_add, scheduling_delete, scheduling_update, scheduling_show,
learning_create, learning_update, learning_delete, behavioral

Key confusion fixes
-------------------
- "show physics exam task" -> scheduling_show
- "show my behavioral summary" -> behavioral
- "I need to learn python" -> learning_create
- "I need to learning python" -> learning_create (typo/noise)

Generate datasets
-----------------
cd CLF_Improvement/generators
python3 sync_slots_from_notebooks.py
PER_TEMPLATE=150 AUGMENT_PER_ROW=3 python3 build_dataset.py
