PHASE 5 — NEW API ENDPOINT
====================================================================
[ ] 5.1  POST /api/profile/avatar (protected, multipart/form-data)
         - Auth: Eva JWT (same as other profile routes)
         - Body: file field "avatar"
         - Flow:
             1. Validate file
             2. Load user's current profile_picture_public_id
             3. Upload to Cloudinary
             4. Update User: profile_picture = secure_url, profile_picture_public_id = public_id
             5. Delete previous Cloudinary image if public_id existed
             6. Return updated toPublicProfile()
[ ] 5.2  Response 200:
