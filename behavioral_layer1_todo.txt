Productivity Scoring System — Complete TODO
================================================================

OVERVIEW
================================================================

  Current approach : frequency counting (shallow)
  New approach     : weighted productivity scoring

  Productivity score per (day, hour) slot combines:
    → Volume     — how many tasks completed (weighted)
    → Reliability — how often completed on time
    → Efficiency  — how fast relative to estimated duration
    → Recency     — recent completions weighted higher
    → Penalty     — rescheduling reduces slot score

  Threshold system:
    → Global : 20 completed logs before any analytics
    → Per day: 5 completed logs before that day scores


================================================================
SCORING FORMULA
================================================================

  Per log — time decay weight:
  ─────────────────────────────────────────────────────────
    weight = e^(-0.01 × days_since_completion)

    7 days ago  → 0.93
    30 days ago → 0.74
    90 days ago → 0.41

  Per (day, hour) slot:
  ─────────────────────────────────────────────────────────
    volume_score      = sum(weights in slot)
                        / max slot weight sum across all slots
                        → normalized 0-1

    reliability_score = sum(weight for on_time logs in slot)
                        / sum(all weights in slot)
                        → 0-1

    efficiency_score  = weighted average of
                        min(task_duration / time_taken, 1.0)
                        → 0-1
                        → skip log if time_taken_minutes null

    reschedule_penalty = 1 - min(avg_reschedule_count / 3, 0.5)
                        → reschedule 0 times → penalty = 1.0 (none)
                        → reschedule 3+ times → penalty = 0.5 (max)

    slot_score = (
        0.35 × volume_score +
        0.40 × reliability_score +
        0.25 × efficiency_score
    ) × reschedule_penalty

  Hour range building:
  ─────────────────────────────────────────────────────────
    PRODUCTIVITY_THRESHOLD = 0.6
    MERGE_THRESHOLD        = 0.6

    hours scoring above threshold → merge consecutive into range
    e.g. hours 18, 19, 20 all above 0.6 → "6PM-9PM"
    gap between hours → separate ranges, not merged

  Threshold check:
  ─────────────────────────────────────────────────────────
    global  : total completed >= 20 → proceed
    per day : logs on that day >= 5 → day included in rankings
              logs on that day < 5  → day excluded, flagged


================================================================
WHAT THIS ENABLES
================================================================

  1. "What is my most productive day?"
     → aggregate slot scores by day
     → rank reliable days only
     → EVA explains which days have insufficient data

  2. "What is my best time on Monday?"
     → filter slots where day = Monday
     → rank by score
     → merge top hours into range
     → EVA: "Your best window on Monday is 6PM-9PM"

  3. Task scheduling suggestion when time missing
     → add handler calls scoring engine
     → returns best range for that day
     → EVA: "Your best window on Mondays is 6PM-9PM.
             Want me to use that or pick a different time?
             1. Use 6PM
             2. Enter a time"

  4. Task scheduling suggestion when date also missing
     → scoring engine returns best reliable day
     → and best range for that day
     → EVA suggests both together

PHASE 5 — CORE SCORING ENGINE
================================================================

Goal: Scoring engine runs end to end on raw logs
      and produces slot scores, day scores, ranges.

  AI Server — services/productivity_scorer.py (new file)
  ─────────────────────────────────────────────────────────

  [x] Implement score_all_slots(logs) → dict
      Input  : list of log dicts from DB
      Output : dict of (day_int, hour_int): score_float

      Algorithm:
        for each log:
          days_ago = days_since(log.action_timestamp)
          weight   = compute_time_decay(days_ago)

        for each unique (day, hour) slot:
          volume_raw      = sum(weights for logs in slot)
          on_time_raw     = sum(weight for on_time logs in slot)
          efficiency_vals = [min(duration/time_taken, 1.0)
                             for logs with time_taken not null]
          avg_reschedule  = avg(reschedule_count for slot logs)

          reliability_score  = on_time_raw / volume_raw
          efficiency_score   = weighted avg of efficiency_vals
                               or 0.5 if no time_taken data
          reschedule_penalty = 1 - min(avg_reschedule/3, 0.5)

        volume_scores = normalize_scores(volume_raw per slot)

        for each slot:
          slot_score = compute_slot_score(
            volume_scores[slot],
            reliability_score,
            efficiency_score,
            reschedule_penalty
          )

        return { (day, hour): score }

  [x] Implement get_productive_hours(logs,
                                     day=None) → list
      → if day given: filter logs for that day
      → call score_all_slots on filtered logs
      → if day given: keep only slots matching day
      → call get_best_range_for_day
      → return list of:
          {
            hour         : 18,
            hour_display : "6PM",
            score        : 0.87,
            on_time_rate : 0.91,
            log_count    : 12
          }
        sorted by score descending

  [x] Implement get_productive_days(logs,
                                    day_log_counts,
                                    per_day_threshold) → dict
      → call score_all_slots(logs)
      → call aggregate_day_scores(slot_scores)
      → call filter_reliable_days(day_log_counts,
                                   per_day_threshold)
      → return:
          {
            reliable: [
              { day: "Tuesday", day_num: 1,
                score: 0.84, log_count: 12,
                on_time_rate: 0.89 },
              ...
            ],
            unreliable: [
              { day: "Wednesday", day_num: 2,

  [x] Implement get_best_time_for_day(logs, day,
