================================================================

Goal: All aggregation queries needed by behavioral handler
      exist and are independently tested.

  AI Server
  ─────────────────────────────────────────────────────────

  [x] Add to db/activity_logs.py:

      count_completed(user_id) → int
        → already exists — confirm it works
        → db.activity_logs.countDocuments({
            user_id: user_id,
            action_type: "task_completed"
          })

      get_hours_distribution(user_id, day_of_week=None) → list
        → aggregates completions by hour_of_day
        → optional filter by day_of_week (0=Monday, 6=Sunday)
        → also computes on_time_rate per hour
        → returns list sorted by count descending:
          [{ hour: 18, count: 12, on_time_rate: 0.91 }, ...]

      get_days_distribution(user_id) → list
        → aggregates completions by day_of_week
        → computes on_time_rate per day
        → returns all 7 days sorted by count descending:
          [{ day_name: "Tuesday", day_num: 1,
             count: 18, on_time_rate: 0.89 }, ...]

      get_completion_rate(user_id) → dict
        → total completed, on_time count, late count,
          on_time_rate percentage
        → also returns weekly trend (last 4 weeks):
          [{ week: 15, count: 7 }, ...]
        → returns:
          {
            total_completed : 42,
            on_time         : 33,
            late            : 9,
            on_time_rate    : 78.5,
            weekly_trend    : [...]
          }

      get_avg_time_taken(user_id) → float or None
        → average time_taken_minutes across all completed logs
        → returns None if no logs with time_taken set

  [x] Add to db/tasks.py:

      get_tasks_for_day(user_id, day_of_week) → list
        → returns tasks scheduled on that weekday
        → used for conflict check in best_time_for_day
        → query: owner_id=user_id, is_deleted=false,
                 day_of_week(due_datetime) = day_of_week
        → returns list of { due_datetime, duration }

  [x] Add to utils/date_utils.py:

        → "wednesday" → 2
        → "thursday" → 3
        → "friday" → 4
        → "saturday" → 5
        → "sunday" → 6
        → case insensitive
        → returns None for invalid input

      hour_to_12h_format(hour) → str
        → 18 → "6PM"
        → 10 → "10AM"
        → 0  → "12AM"
