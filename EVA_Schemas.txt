================================================================
EVA — DATABASE SCHEMAS (ALL COLLECTIONS)
================================================================

Total Collections : 11
Database          : MongoDB Atlas
================================================================

COLLECTION OWNERSHIP
================================================================

  AI Server owns (full read/write):
    Tasks, Learning_Goals, Roadmap_Topics, Activity_Logs,
    Conversation_History (insert), Chat_Sessions (update)

  Node.js owns (full read/write):
    Users, Friends, Notifications, Chat_Sessions (insert),
    User_Settings, Integrations

  AI Server reads only:
    Users, Friends, User_Settings, Integrations

================================================================

2. TASKS
================================================================

  ──────────────────────────────────────────────────────────────
  task_id        ❌         ObjectId, PK                Unique identifier

INDEXES (RECOMMENDED)
================================================================

  Tasks:
    { owner_id: 1, due_datetime: 1 }          → fetch tasks by user + date
    { owner_id: 1, status: 1 }                → filter by status
    { owner_id: 1, priority: 1 }              → filter by priority
    { owner_id: 1, is_deleted: 1 }            → soft delete filter
    { owner_id: 1, title: 1, due_datetime: 1 }→ duplicate check

  Activity_Logs:
    { user_id: 1, action_type: 1 }            → count completed logs
    { user_id: 1, day_of_week: 1, hour_of_day: 1 } → behavioral analytics

  Conversation_History:
    { session_id: 1, created_at: -1 }         → fetch history for context

  Notifications:
    { user_id: 1, is_read: 1 }                → unread notifications
    { scheduled_at: 1 }                       → reminder job queries

  Friends:
    { requester_id: 1, recipient_id: 1 }      → friendship check
    { recipient_id: 1, status: 1 }            → pending requests

  Learning_Goals:
    { user_id: 1, status: 1 }                 → active goals

  Roadmap_Topics:
    { goal_id: 1, order: 1 }                  → ordered roadmap fetch

  roadmap_resources:
    { language: 1, level: 1, order: 1 }       → fetch ordered sessions for a level
    { language: 1, level: 1 }                 → all docs for a level
    { fetched_at: 1 }                         → YouTube refresh / unfetched queries
