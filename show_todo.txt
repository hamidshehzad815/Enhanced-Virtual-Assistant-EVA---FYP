Goal: Show handler runs STEP 1 to STEP 4.

      → if date present: call Duckling → build_date_range
      → if Duckling fails on date: treat as no date filter
        (do not ask user — just proceed with no date)
      → if date absent: set upcoming filter (>= now_utc)

  [ ] Implement STEP 2 — query tasks
      → call find_tasks_for_show(user_id, filters)
      → receive (results, total_count)

  [ ] Implement STEP 3 — handle result count
      → 0 results:
          determine which filter was used
          call Gemini with context-aware not-found prompt
          return → STOP

          convert to local timezone
          pass to STEP 4
      → total_count > 10:
          pass first 10 to STEP 4 with has_more=True

  [ ] Implement STEP 4 — Gemini format and return

      → save EVA reply to Conversation_History
      → update Chat_Session
      → return { status, response_text, notifications: [] }

                       total_count, has_more)
          → handles single task, multi-day grouping, has_more

  [ ] Handle special cases:
      → status = "complete": adjust sort to descending
      → no entities: query upcoming, no filter label
      → multiple filters combined: all applied together
